# Property Valuation ML Pipeline

This repository contains the code and resources for a machine learning pipeline designed to estimate property values.

## Overview

- Data collection and preprocessing
- Model training and evaluation
- Prediction and deployment

## If you use Conda:

If you use Conda:

conda env create -f environment.yml
conda activate property-friends-env

This environment is intended for local development and testing.
The Docker container uses a lean requirements.txt for reproducibility.
